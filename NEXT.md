## Where it stands

The starter kit works: a template repository for training small language models in 10-minute experiments on a home GPU, with an agent as the researcher, an experiment record (`record.py`, `lab.py`), sample capture, an unattended session runner and a side-by-side browser page. The hosted demo at https://autoresearch-demo.fly.dev/ answers and serves eight models from two 10-hour sessions. The last changes, merged on 24 October, were the console progress in `session.py` and the README's description of the eight-model demo. No issue or pull request is open.
